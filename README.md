# Bài tập CSS – Buổi 3

**Sinh viên:** Minh Phát  
**Môn học:** Phát triển ứng dụng WEB/TMĐT  
**Giảng viên:** TS. Nguyễn Mạnh Tuấn

## Nội dung thực hiện

Repository này lưu trữ các bài tập CSS Buổi 3, bao gồm:

- Bài 2: Thực hành định dạng văn bản và nội dung bằng CSS.
- Bài 4, 5, 6, 7: Thực hành các thuộc tính CSS và bố cục trang web.
- Bài 8: Định dạng giao diện Bat Family và tạo hiệu ứng Hover.
- Bài 9: Sử dụng thư viện Font Awesome để chèn các biểu tượng.
- Bài 10: Tạo trang chủ `index.html` liên kết đến các bài tập và giới thiệu thông tin cá nhân.

## Cấu trúc thư mục

- `VeNha/`: Chứa các file HTML và CSS của bài tập.
- `VeNha/images/`: Chứa hình ảnh sử dụng trong các bài tập.

## Kết quả

Các bài tập được xây dựng bằng HTML và CSS, sử dụng thêm thư viện Font Awesome ở Bài 9. Trang `VeNha/index.html` đóng vai trò là trang chủ để truy cập các bài tập đã thực hiện.
